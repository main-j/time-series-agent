## noise.py
**amplitude:** Noise amplitude  
**length:** Sequence length  
**type:** Type  
**n_rate:** Noise interval ratio, range 0-1  

## trend.py
**amplitude:** Trend amplitude  
**delta_s:** Upper bound of the second derivative, randomly truncated using a uniform distribution  
**length:** Sequence length  
**type:** Type, categorized as amplitude-limited (with constraints on the start-end difference) and non-amplitude-limited (without constraints on the start-end difference)  
**delta:** Initial slope  
**const:** Whether the starting value is fixed  

## season.py
**type:** Category, includes preset types such as sine wave, square wave, random periodic signal, random traffic signal, etc.  
**wavnum:** Number of components for sine or square waves  
**seq:** Preset periodic segment; if randseason is available, it will be used; otherwise, one is randomly generated by default  
**delta_s:** Upper bound of the second derivative within a period  
**shake_factor:** Amplitude variation range within a period  
**limit_type:** Whether amplitude is constrained during intra-period trend generation  
**levels:** Quantization levels, generally not used  
**flex_factor:** Time variation range within a period  
**smooth:** Not used
